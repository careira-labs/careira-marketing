## Notes

- Use PNG format with good compression
- Ensure text is readable at specified dimensions
- Maintain Careira brand colors and design system
- Screenshots should show real UI (not mockups or placeholders)
- Crop/frame to highlight the relevant features for each step

## After Adding Screenshots

Once you've added all screenshots, test the landing pages:
1. Run `npm install` (first time only)
2. Run `npm run dev`
3. Open `http://localhost:3000/jobseekers`
4. Open `http://localhost:3000/recruiters`
5. Verify all images load correctly
